🌐 100% Free Permanent Cloud Database Setup Guide

Render free web services use ephemeral local disks, which reset when the app sleeps. To make student records, logs, and user accounts survive server restarts permanently for $0/month, connect a free Cloud PostgreSQL database:

Option A: Neon.tech (Recommended)
1. Sign up at neon.tech (Free Tier).
2. Create a project and copy the Connection String.
3. On Render Dashboard → Environment → Add Variable: `DATABASE_URL` = your Neon PostgreSQL URL.
Option B: Supabase
1. Create a free project at supabase.com.
2. Go to Database Settings → URI.
3. Set `DATABASE_URL` on Render to your Supabase PostgreSQL connection string.
